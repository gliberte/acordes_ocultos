Laptop con Windows para «Acordes Ocultos»

Especificaciones técnicas mínimas y punto óptimo para renderizado local y flujos de IA

🎯 1. Resumen Ejecutivo y Diagnóstico de Carga

Para invertir lo menos posible sin arriesgar la estabilidad del flujo de trabajo, es indispensable comprender cómo se distribuye la carga operativa entre tu equipo físico y la nube:

☁️ En la Nube (No consume tu hardware)

  • Generación de Imágenes: Servidores de Google (Google Flow / Gemini Imagen) o modelos externos.
  • Inteligencia Artificial y Razonamiento: Claude / Gemini procesan guiones y crónicas de forma remota.
  • Distribución y Archivo: Cloudflare R2, Supabase y Google Drive.

🖥️ En tu Laptop (Requiere hardware real)

  • Renderizado Remotion: Ejecuta instancias paralelas de Chromium para dibujar 2.700 fotogramas (1080x1920 a 30fps) y los comprime con FFmpeg (H.264).
  • Automatización Playwright: Levanta sesiones de navegador headless para descargar recursos.
  • Sistema Operativo: Windows 11 consume ~4 GB de RAM en reposo.

⚠️ 4. Trampas Comerciales que Debes Evitar

🚫 1. Laptops con 8 GB de RAM soldada (Sin ranura de expansión)

Muchos modelos baratos traen 8 GB soldados directamente a la placa base. No las compres: en Windows 11 no podrás renderizar sin bloqueos. Si compras una de 8 GB por oferta imperdible, asegúrate al 100% de que tenga una ranura libre para agregar un módulo de 8 GB adicional ($20 USD).

🚫 2. Procesadores Intel Celeron, Pentium o Core i3 de 2 núcleos

Estos chips son insuficientes para codificación concurrente de video. Un renderizado de 90 segundos que debe tomar 2 minutos tardará más de 20 minutos con el procesador al 100% de temperatura.

🚫 3. Laptops «Gamer» con tarjeta Nvidia dedicada (RTX 3050/4050)

Cuestan entre $800 y $1.100 USD, pesan el doble y la batería dura apenas 2 horas. Remotion y Playwright no aprovechan esta GPU para renderizado vertical básico y la IA se ejecuta en la nube. Sería un gasto innecesario de dinero.

🛠️ 5. Pasos de Puesta a Punto en Windows 11

Una vez que recibas tu equipo, ejecuta esta secuencia de instalación para dejar el entorno operativo:

# 1. Instalar FFmpeg en Windows (vía PowerShell como Administrador):
winget install Gyan.FFmpeg

# 2. Instalar Node.js LTS (versión 20 o 22) desde:
https://nodejs.org/

# 3. Instalar Git para Windows desde:
https://git-scm.com/

# 4. Clonar el repositorio y levantar el entorno:
git clone <url-de-tu-repositorio>
cd acordes_ocultos
npm install
npx playwright install chromium
